# Templers-Cafe-Network-Design
Proposed network infrastructure design for Templers Cafe, focusing on VLAN segmentation, network security and POS connectivity

## Project Overview
This project focuses on proposing an improved network infrastructure for Templers Cafe, a small privately owned cafe.

## Problem Identification
The existing network uses a single consumer router for guest Wi-Fi, staff devices and the POS system, resulting in connectivity and performance issues during busy periods.

## Proposed Solution
- VLAN segmentation for Guest, Staff and POS networks
- UniFi Gateway and Firewall
- Wi-Fi 6 Access Points
- Quality of Service (QoS)
- Improved network security and reliability

## Technologies and Concepts
- Computer Networking
- VLAN Configuration
- Network Segmentation
- Firewall and Network Security
- QoS
- Wireless Networking
